Redlimit is a cybersecurity company in Jakarta, founded in 2022. We run penetration tests and security audits for Indonesian organizations, build the platforms below, and teach through Meta4sec, the community we started.

## Platforms

| | |
| --- | --- |
| [**Dettack**](https://dettack.com/) | Attack surface management. Scans your domains from the outside with no agents and no credentials. Incident Check catches defacement, gambling injection, and SEO spam that ordinary scanners walk past. |
| [**CTF Lab**](https://hack.redlimit.id/) | 125+ hands-on challenges across 8 categories, with guided paths for bug bounty, CTF, and SOC work. The blue team labs come from real Indonesian incidents. |
| [**Academy**](https://academy.redlimit.id/) | Instructor-led courses: pentest bootcamps, security fundamentals, and awareness training. |
| [**HackTools**](https://tools.redlimit.id/) | Free browser toolkit for recon and bug bounty work: dork generators, subdomain discovery, JS file analysis, header checks, and payload builders. |
| [**BBRD**](https://wu.redlimit.id/) | 4,800+ public bug bounty writeups across 751 programs, indexed by vulnerability class and bounty value. |

Our engineering work is private today. Anything we open source will land in this organization.
